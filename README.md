# AstraViewer

Create space scenery (planets, stars, black holes, asteroid fields, starry skies) by simply describing it, then
export it as images or 3D scenes.

**[Version française plus bas](#français)**

## Install (Windows 10 or 11)

1. **Download** the installer: open the [latest version](https://github.com/HugoHumbert/AstraViewer-releases/releases/latest)
   and click `AstraViewer-Setup-….exe` under **Assets**.
2. **Open** the downloaded file.
   Windows may say "Windows protected your PC" (the app is not signed yet): click **More info**, then **Run anyway**.
3. **Follow the installer.** Leave **"Also install the free local AI (Ollama)"** checked: it lets you create with
   prompts for free. The Ollama installer opens at the end: click **Install**.

That's it: AstraViewer opens, and you can find it in the Start menu and on the desktop.

## First launch

The first time, AstraViewer asks to download its AI model: click **Install qwen3:8b** (5.2 GB, once only).

Prefer not to download it? You can use Claude or ChatGPT instead (paid): pick its tab above the prompt and paste an
API key from [console.anthropic.com](https://console.anthropic.com) or [platform.openai.com](https://platform.openai.com).

## Good to know

- **Updates are automatic**: new versions download in the background and install when you close the app.
- **Your creations** are saved in `Documents\AstraViewer\library`.
- **Uninstall**: Windows Settings → Apps → AstraViewer.
- A recent graphics card gives the best results, but the app adapts to smaller computers.
- Not available yet on macOS or Linux.

## Français

Créez des décors spatiaux (planètes, étoiles, trous noirs, champs d'astéroïdes, ciels étoilés) en les décrivant
simplement, puis exportez-les en images ou en scènes 3D.

### Installer (Windows 10 ou 11)

1. **Téléchargez** l'installeur : ouvrez la [dernière version](https://github.com/HugoHumbert/AstraViewer-releases/releases/latest)
   et cliquez sur `AstraViewer-Setup-….exe` sous **Assets**.
2. **Ouvrez** le fichier téléchargé.
   Windows peut afficher « Windows a protégé votre ordinateur » (l'application n'est pas encore signée) : cliquez
   sur **Informations complémentaires**, puis **Exécuter quand même**.
3. **Suivez l'installeur.** Laissez cochée la case **« Installer aussi l'IA locale gratuite (Ollama) »** : elle permet
   de créer par prompt gratuitement. L'installeur d'Ollama s'ouvre à la fin : cliquez sur **Install**.

C'est tout : AstraViewer s'ouvre, et vous le retrouvez dans le menu Démarrer et sur le bureau.

### Premier lancement

La première fois, AstraViewer propose de télécharger son modèle d'IA : cliquez sur **Installer qwen3:8b**
(5,2 Go, une seule fois).

Vous préférez ne pas le télécharger ? Vous pouvez utiliser Claude ou ChatGPT à la place (payants) : choisissez son
onglet au-dessus du prompt et collez une clé d'API créée sur [console.anthropic.com](https://console.anthropic.com)
ou [platform.openai.com](https://platform.openai.com).

### Bon à savoir

- **Les mises à jour sont automatiques** : les nouvelles versions se téléchargent en arrière-plan et s'installent
  quand vous fermez l'application.
- **Vos créations** sont enregistrées dans `Documents\AstraViewer\library`.
- **Désinstaller** : Paramètres de Windows → Applications → AstraViewer.
- Une carte graphique récente donne les meilleurs résultats, mais l'application s'adapte aux ordinateurs plus modestes.
- Pas encore disponible sur macOS ni Linux.
